# 安全性、协议兼容性及部署验证补充报告

本轮基于修复分支开展修改和测试，遵循 IETF 隧道语义、安全性和大规模部署可靠性的目标。未部署生产、推送远端或修改用户原始检出目录。测试通过不能证明软件无缺陷，也不是 Apple 官方认证。

## 确认的问题与处理

| 问题 | 触发方式及原因 | 后果 | 本轮处理 |
|---|---|---|---|
| 认证失败日志可被放大 | 重复发送已缓存的错误凭据，仍逐请求输出警告；实测 200 次请求产生 200 条警告 | 消耗日志 I/O、存储和采集容量 | 进程共享认证日志预算 5 条/秒、突发 10 条；下次输出附带抑制数。诊断请求日志独立限制为 10 条/秒、突发 20 条 |
| 有效账户缺少总流量预算 | 并发隧道数有限，但合法账户仍可持续产生高字节率或高 UDP 包率 | 争抢带宽、CPU 和 socket 处理能力，损害其他用户 | 增加每用户共享字节率及 UDP 包率配置；上传、下载、所有隧道共用预算，重连不恢复突发额度，策略不变的同域重载延续预算 |
| 限速等待线程退出不完整 | 对端重置时复制函数返回，但等待额度的线程可能仍持有父请求上下文 | 很低的速率配置下，线程和缓冲区滞留 | 为复制过程创建内部可取消上下文，函数退出即取消；五次回归检查预留额度及时释放 |
| 安装事务缺乏互斥 | 两个安装进程同时读取旧状态、构建、备份和替换 | 文件/服务状态交错、恢复错误版本 | 在读取安装状态前取得私有 root 目录内的 flock；备份改为权限私有的唯一临时目录 |
| 回滚混淆启用与运行状态 | 原服务已启用但未运行时，失败回滚将它禁用；此前还可能误报旧服务继续运行 | 下一次启动不自动恢复服务，运维误判 | 分别保存并恢复 active/enabled 状态；首次安装失败先停止/禁用候选服务，再移除 unit；错误消息按真实旧状态描述 |

字节预算默认 0，表示无限制；UDP 包率同样默认 0。生产必须依据用户负载配置预算，并结合入口限速与主机资源上限。字节突发额度 128 KiB；包突发额度为 min(配置包率, 1024)。这提供总量上限，不保证同一用户各隧道之间的调度公平，也不限制已到达服务的所有网络开销。

TCP 限速采用背压与可取消等待，不改变字节内容或 FIN/RST 语义。UDP 超额包直接丢弃，不改用可靠流传送，不绕过路径 MTU 和禁止分片策略。流量策略改变时撤销旧隧道，避免旧策略持续生效。日志现在是采样日志，不能用于逐请求完整计数。

## 已完成的验证

- HTTP/1.1、HTTP/2、HTTP/3 均验证了 TCP 字节预算、数据完整性及 UDP 包率限制；重载预算共享和账户隔离有回归检查。
- 1,000 个独立账户/H3 连接同时保留：重载后继续传输；总量上限不可绕过；关闭后隧道、H3 和用户配额计数归零。竞态检查开启，客户端与服务端位于同一进程，合计堆增长 260.6 MiB、FD 增长 5,000。16 个接入工作线程下，接入 p50 1.433 秒、p99 2.009 秒。这不是生产服务器资源估算或容量承诺。
- 独立 Caddy 进程运行于真实 Debian 12 systemd：三种协议 TCP/UDP 及无凭据拒绝检查通过；两个 H3 隧道各双向传输 64 MiB 通过。
- 真实 systemd 故障注入验证：原服务运行且启用、停止但启用、停止且禁用，以及首次安装失败四种情况。实验预装依赖并注入启动失败候选程序；实际配置验证、服务管理和恢复均未使用 systemctl 替身。
- 安装器 16 项自动测试通过。Linux/Darwin × amd64/arm64 编译通过。完整竞态、上游传输测试、模糊测试、静态检查和漏洞扫描详细结果在 production-readiness.md 与本地证据中记录。
- Go 1.26 的一次并发全量运行暴露了 MTU 测试回声端自身的错误：两端独立探测，服务端尚不能回送大包时测试端直接退出。修正测试端在原时限内进行自身探测，20 次竞态重复通过。未放宽产品 MTU 限制或测试时限。

## 尚不能据此宣布生产验收完成

1. Apple 真机各受支持系统版本、配置描述文件安装及管理模式尚需验收；Darwin 编译通过不等于其原生 socket 行为验证。
2. Wi-Fi/蜂窝切换、真实 IPv6/NAT64、不同公网 MTU、证书轮换及公网 ACME 尚需目标环境验证。
3. 需要明确设备数量、峰值带宽、包率和延迟目标，配置预算、FD/内存上限、出口防火墙与回滚阈值，然后做生产网络灰度。云 NAT 公网映射及邻接网段不能仅依赖接口地址检查保护。
4. 漏洞扫描使用官方 GitHub OSV 快照，未发现可达调用风险；不代表未来公告或本地传输补丁不存在问题。发布前应更新数据库并复核补丁。

IETF 相关回归覆盖 CONNECT/CONNECT-UDP、HTTP/2/3 扩展 CONNECT、Capsule/Datagram、半关闭、拒绝/重置、路径 MTU 及禁止分片。测试覆盖与实现审查不能代替对所有部署路径的形式化合规证明。
