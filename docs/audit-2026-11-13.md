## Latest native diagnosis and historical recheck

Raw HTTP/2 frame observations reproduce the same 63-byte UDP truncation on
macOS 15.8.2 and 27.0.1. The native sender's frame declares 66 bytes with flags
0x0, although its Capsule header requires 67 bytes. The final payload byte is
already absent before server DATA parsing, padding removal or request-body
buffering. This explains the recorded continuous-stream desynchronization and
inner-HTTP/3 upload stalls. Independent Go clients pass 42 uploads of 64 MiB.
